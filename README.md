# Sistema SGMDE

Sistema de Gestão de Matrículas e Documentos Escolares desenvolvido como parte do Projeto Integrador.

## 📌 Descrição
O sistema permite o gerenciamento de alunos, matrículas e documentos escolares.

## ⚙️ Funcionalidades
- Login
- Dashboard
- Navegação entre telas
- Cadastro de aluno
- Matrícula
- Documentos
- Relatórios

## 🚀 Tecnologias
- Python (Flask)
- HTML
- CSS
